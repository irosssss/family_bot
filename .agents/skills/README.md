# Навыки Family Life RPG

Источник: https://github.com/gamedev-skills/awesome-gamedev-agent-skills
Ревизия: b105e1cf617adf0b68ed98790a716bbb60993179.
Полные папки upstream со справочниками и скриптами; лицензия UPSTREAM_LICENSE,
атрибуция UPSTREAM_NOTICE. Сторонние скрипты при установке не запускались.

- create-game-assets: готовые ассеты Figma, размеры, прозрачность, подготовка контента.
- game-ui-ux: мобильная навигация, окна, читаемость.
- game-feel: отклик удара и победы после проверки механики.
- save-systems: совместимость сохранений и обновлений.
- rpg: структура каталога и прогресса, в рамках правил V3.
- performance-optimization: измеренная проблема производительности.

Читать только подходящий SKILL.md и необходимые references. Router и движки не
устанавливались: проект React/Vite. Figma/imagegen доступны через существующие плагины.
Решения владельца и AGENTS.md выше общих игровых шаблонов. Готовые ассеты переиспользовать;
косметика не даёт силу, родители играют, общий путь без наказаний. Не добавлять механику
лишь потому, что она указана в навыке. Обновлять навыки отдельным проверенным diff
с закреплением новой ревизии, сохраняя лицензию и атрибуцию.
