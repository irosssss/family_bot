# AGENTS.md — Family Life V3

V3 — единственная рабочая версия. Источник принятых правил: `docs/V3_BASELINE.md`.
React 18 + Vite; mobile-first 375–390px. Текущий runtime локальный, с журналом в браузере.

## Запуск и проверки

- `npm run dev` — http://127.0.0.1:3217/; без БД и секретов.
- `npm run lint`, `npm run content:v3:validate`, `npm test`, `npm run build`.
- Подготовленные серверы: `docs/maintenance/PREPARED_MODULES.md`.
- Не запускать старые миграции/контейнеры для просмотра интерфейса.

## Правила V3

- Родители участвуют: свои дела, монеты и XP; за проверку чужих дел награды нет.
- При создании дела выбирается режим проверки. Проверяемое своё дело принимает другой
  взрослый; единственный взрослый подтверждает отдельно.
- Комплект №1 бесплатный; №2 48, №3 72, сезонные 120. Косметика не даёт боевой силы.
- Общий босс семьи; сила личная, удар кнопкой, без наказаний. Первая глава: 10 силы/дело,
  60 HP; избыток сохраняется. Сила выдаётся только после начала кампании.
- Не менять ключи и формат сохранённого журнала без миграции; не сбрасывать семью при QA.
- Эмодзи в интерфейсе запрещены. Использовать утверждённую графику V3 и lucide.
- Старые приложения и их ассеты удалены из рабочей структуры; восстановление — через Git.
  Не копировать их обратно ради обхода ошибки.

## Рабочая структура

`src/v3/` — интерфейс и локальная логика; `content-source/v3/` — каталог с ContentId;
`public/assets/game/` — действующие ресурсы; `docs/` — правила, планы, аудиты.
`src/target/`, `src/v3-server/` — подготовка будущей серверной интеграции, не актуальный UI.

## Память проекта и маршрутизация инструментов

Для новых дизайн-направлений и выбора средств проверки см. `docs/tooling/DEVELOPMENT_WORKFLOW.md`.
Inspo использовать по необходимости для референсов; существующий дизайн-контракт важнее
внешней рекомендации. ARTEMIS — только для подготовленного Android-стенда; SoL-Pi не
является расширением Codex. Статусы интеграций: `docs/tooling/RESEARCH_2026-09-21.md`.

Перед новой задачей прочитай компактную память проекта в `docs/AGENT_MEMORY.md`.
Обновляй её только после подтверждённых изменений архитектуры, найденных runtime-проблем,
решений по аудиту или изменения рабочего процесса. Не дублируй туда код и не записывай
секреты, токены или персональные данные.

Для локального кода используй `rg`, `apply_patch`, `npm run lint`, `npm test` и браузерную
проверку. Доступность внешнего скила всегда проверяй в текущем рантайме: список Hermes
выше — каталог рекомендуемых паттернов, а не гарантия, что скилл callable в каждой сессии.

1. **Proof over claims**: визуальное изменение = скриншот/превью, а не «должно работать».
2. Новый ассет = строка в `docs/ASSET_MANIFEST.md` (Name/Size/Path/Used-by).
3. После правок: `npm run lint` → 0 ошибок, релевантные тесты, сборка и проверка в браузере.
4. Кнопки ≥44px, сцены адаптивны (проверяй на 375px).
5. Ассеты в `public/assets/game/` — только то, что грузится рантаймом. Генерация-инпуты держи вне.
