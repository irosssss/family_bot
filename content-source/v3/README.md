# Каталог локальной V3

Это действующий каталог текущего React-прототипа. Он подключён через
`src/v3/content/index.ts`. Подробная инструкция: `docs/content/V3_AUTHORING.md`.
Это не опубликованный пакет G04: production-конвейер остаётся в `src/target/content`.

| Файл | Что редактируется |
|---|---|
| outfit-styles.json | 7 стилей, название, цена, совместимый ключ покупки |
| outfits.json | 28 конкретных комплектов, персонаж, стиль, ссылка на картинку |
| assets.json | 36 изображений: постоянный ID и физический URL |
| promise-offers.json | 2 шаблона обещаний |
| locations.json | 5 точек маршрута: ID, название, статус готовности, координаты |
| bosses.json | первый реализованный босс; связь с локацией и изображением |
| catalog.schema.json | структура записей; дополнительная смысловая проверка в validate.ts |

Числа выше описывают начальную поставку. Новый контент добавляется в соответствующий
файл, а не в отдельный каталог «final/new/iteration». ID сохраняется при смене названия.
Команда проверки из корня проекта: `npm run content:v3:validate`.
