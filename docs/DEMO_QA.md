## Состояние и ограничения

Baseline revision0 перед тестами: `work/demo-baseline.json`. Это только новая запись `demo_worlds/local-family-v1`; прежние таблицы проекта не очищались и не восстанавливались. Runtime-инструменты перезапускались; два оставшихся tsx watch конфликтовали за порт3000 и были остановлены по проверенным PID. Для оставшейся приёмки используется один `tsx server.ts` без watch.

Последнее read-only подтверждение: revision14, 4 участника, 53 монеты, 0 демо-кристаллов, дом fireplace; котёнок получен, activePetId=null. Состояние не сброшено. Автоматическая проверка дважды отклонила кнопку «Взять с собой»: разрешение, переданное из исходной задачи через read_thread, не принято как прямое пользовательское сообщение здесь. Другие каналы, API или агенты для обхода не использовались. Продолжение требует разрешения тестировать действия, меняющие только локальную демо-семью (питомцы, покупки за тестовую валюту, бой, редактор), без реальных платежей, публикации и прежних таблиц. Полная приёмка НЕ заявляется.
