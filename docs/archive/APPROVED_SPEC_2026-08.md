## 1. 🎨 Структура слоёв персонажа (LPC-совместимая)

```
Z 0   Тень (shadow) — полупрозрачный овал
Z 5   Задний слой: плащ/крылья/рюкзак (back)
Z 10  Ноги (legs)
Z 15  Торс/тело (body)
Z 20  Руки (arms)
Z 25  Одежда верх (shirt/armor)
Z 30  Одежда низ (pants/skirt)
Z 35  Обувь (shoes/boots)
Z 40  Маунт (mount) — под персонажем
Z 45  Голова (head)
Z 50  Лицо (eyes/brows/mouth) — ОТДЕЛЬНЫЙ слой эмоций!
Z 55  Волосы задние (back hair)
Z 60  Волосы передние (front hair)
Z 65  Головной убор (hat/helmet)
Z 70  Щит (shield)
Z 75  Оружие задней руки
Z 80  Оружие передней руки
Z 85  Эффекты (aura/particles)
Z 90  Питомец (pet) — ОТДЕЛЬНЫЙ объект сцены, НЕ слой персонажа!
```

### Ключевые правила:
1. **Питомец — НЕ слой.** Отдельный спрайт-компаньон, следует за персонажем, рендерится ПОСЛЕ него
2. **Слой лица (Z50) — обязателен.** Дети 4-5 лет читают эмоции: улыбка при победе, грусть при провале
3. **Ноги/торс/руки разделены** — можно комбинировать одежду (юбка + рубашка)
4. **Тень (Z0) обязательна** — иначе персонаж "парит" в изометрии

### Прогрессия кастомизации по УРОВНЮ (не по возрасту!):
```
Lv 1-3  Стартовый набор (2 цвета рубашки, 1 причёска)
Lv 4    +3 цвета одежды
Lv 5    🎓 Первый головной убор — "шляпа героя"
Lv 7    +2 причёски
Lv 10   🏰 ВЫБОР КЛАССА: рыцарь/маг/лучник/целитель (ключевая развилка!)
Lv 12   Слот питомца №2
Lv 15   Легендарная экипировка (свечение)
Lv 20   Эпический сет (аура + частицы)
```

### Визуальные эффекты:
| Событие | Анимация | Звук |
|---|---|---|
| Смена одежды | Вспышка света + предмет "налетает" | "equip" (0.3s) |
| Покупка питомца | Яйцо → выпрыгивает → сердечки | "hatch" + щебет (1s) |
| Победа над боссом | Мигает → взрыв → тряска → конфетти → трофей | Эпическая фанфара (2s) |
| Level up | Кольцо света + искры | "level up" (0.8s) |

## 2. 📋 Система задач (утверждённая)

### 2.1. Возрастные группы (ЕДИНЫЕ, критические для кода!):
```
4-5 лет   6-8 лет   9-11 лет   12-13 лет
```
⚠️ В старом TASK_SYSTEM_DESIGN.md были расхождения (4-6/7-9/10-12) — ОТМЕНЯЮ. Используй 4-5/6-8/9-11/12-13.

### 2.2. Количество задач по возрасту:
```
Возраст    Обязательные   На выбор    Всего
4-5 лет    1             1-2         2-3 (МАКСИМУМ 3!)
6-8 лет    2             2-3         4-5
9-11 лет   2-3           3-4         6-7
12-13 лет  3             3-5         8
```

### 2.3. Типы задач (task_type определяет ВСЁ):
- `core` → всегда на выбор
- `personal` → `is_required` решает (гигиена required, хобби optional)
- `quest` → всегда optional, с бонусом

### 2.4. Streak:
```
Streak +1  если: ВСЕ обязательные (personal required) выполнены И их было ≥1
Streak ⏸️   если: обязательных назначено 0
Streak 🔄  если: не все обязательные выполнены
Core и Quest НЕ влияют на streak
```

## 3. 💰 Экономика наград (утверждённая)

### Базовая таблица (для 6-8 лет):
```
Тип задачи      Золото      XP          Кристаллы
Personal (обяз) 15-25       15-25       —
Core (выбор)    20-30       20-30       —
Quest           60-100      60-100      +3-5 💎
Сундук сюрпризов 10-50      10-50       1 💎 (редко, ~15%)
```

### Множитель по возрасту:
```
4-5 лет   ×0.7
6-8 лет   ×1.0 (база)
9-11 лет  ×1.3
12-13 лет ×1.6
```

### Anti-overjustification механики:
1. Награда = base × (0.8 + rand(0.4)) — вариативность
2. Бонус за мастерство: быстро/без напоминаний → +30%
3. **"Сундук сюрпризов"** 1-2 раза в день (неожиданная награда не ломает мотивацию)
4. **Кристаллы ТОЛЬКО за квесты/milestones/achievements**
5. **Признание родителя**: push "Миша помог с уборкой!" + похвала в семейном чате

### Целевая экономика дня (6-8 лет, идеально):
```
~195 золота + 3 💎 в день
С streak 5 дней (+25%): ~240 золота
Предмет за 2-3 дня, питомец за неделю-полторы
```
