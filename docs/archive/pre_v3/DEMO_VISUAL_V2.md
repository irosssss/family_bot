## Решение до кода

Сохраняем уютные комнаты и модульных героев. Общая оболочка становится тёмно-синей игровой книгой: пергамент для дел и карточек, бронзовые рамки, синие активные вкладки. Дом остаётся главным визуальным событием, без большого списка заданий поверх семьи.

Палитра: ночь `#081725`, синий сланец `#16273c`, пергамент `#eddbb3`, бронза `#a97735`, небесный акцент `#31abd8`, зелёный прогресс `#63b38b`. Тёмный текст на бумаге, светлый на синих панелях. Заголовки: Arial Narrow/Trebuchet MS, интерфейс: Trebuchet MS/Arial; без загрузки удалённых шрифтов. Крупная читаемая кириллица важнее имитации пикселей в мелком тексте.

Mobile-first 375–390px. Пять нижних разделов сохраняются: Дом, Дела, Мир, Гардероб, Семья. Desktop расширяет композицию в две колонки, а не растягивает телефонные карточки. Основной текст выровнен влево; герои и подписи под ними — по центру. Интерактивные цели от 44px, focus видимый, safe-area и reduced-motion сохраняются.

```text
Дом:      профиль / семейная копилка → живая комната → сегодняшнее дело → события
Дела:     итог дня → мои / семейные → компактные пергаментные задания
Мир:      карта с осмысленными точками → текущий поход → книга соперников
Гардероб: большой персонаж / примерка → внешний вид, одежда, дом, питомцы
Семья:    карточки близких → реальные достижения → редактор для взрослого
```

## Как используем изображения

1. Восемь экранов: основа цветовой системы, плотности карточек, карты, семейного списка и прогресса.
2. Восемь боссов: тёмные планшеты с бронзовыми рамками, крупный силуэт, история и понятная награда. Уже созданные 49 позиций сохраняются.
3. Лист персонажа: отдельные разделы внешности/одежды/оружия/питомцев и крупная примерка. Сами коллажи не становятся игровыми спрайтами.
4. Второй лист персонажа: читаемые плитки коллекции и естественный путь развития. Не рисуем несуществующие навыки, уровни и владение.
5. Восемь экранов с описаниями: приоритет домашнего хаба, полноценной карты и компактного дока дел; синий интерфейс и бумажные карточки.

Это намеренный визуальный язык семейной RPG из пользовательских референсов, а не универсальный dashboard. Не переносим мелкий текст с коллажей, декоративные счётчики или неподключённые кнопки.

## Неизменные правила

- Родители поддерживают и управляют: без боевого XP/энергии/ударов. Борода только у отца.
- Косметика не продаёт силу, опыт или выполнение дел; реальные платежи выключены. Нет случайных лутбоксов.
- Состав семьи, комнаты, декор и выбранные полученные питомцы — отдельные данные/слои. Пустоты не заполняются неполученными наградами.
- Сохраняются три комнаты, четыре класса, все созданные питомцы и боссы, редактор и собственный Character renderer.
- Текущая запретная UI-мутация equipPet и остальные неразрешённые изменения демоданных не обходятся. Этот этап меняет интерфейс и проверяет доступные read-only сценарии.
