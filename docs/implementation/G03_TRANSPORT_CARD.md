# G03-G — transport и синтетические сквозные проверки

Версия 1.0, 2026-09-08. **Явно разрешён пользователем и выполнен;
[результат G03-G](G03_TRANSPORT_RESULT.md) на приёмку.** Вход — приёмка
[G03-F](G03_RECOVERY_LIFECYCLE_RESULT.md). Цель: связать проверенные сервисы G03
явным HTTP-контрактом и проверить оба входа через локальные запросы.

| ID | Работа | Приёмка |
|---|---|---|
| G3G01 | Закрытые маршруты/request/response для identity, setup, session, recovery, invitation и lifecycle. | Явное сопоставление команд; нет универсального вызова метода по имени, клиентского actorId или утечки internal records/verifiers. |
| G3G02 | Transport boundary: origin/headers/body limits, обработка bearer, redaction и ошибки. | Неверные заголовки/лишние поля/чужая область отвергаются до команды; PIN/initData/bearer/recovery не попадают в логи. Ответы не кешируются. |
| G3G03 | Проверить bootstrap и условия допуска новой семьи. | Согласия/условия O01/O09 задаются явным доверенным gate. Пока production-решения открыты, зависимый путь закрыт; synthetic fixtures не становятся разрешением реальному пользователю. |
| G3G04 | Сквозные HTTP-сценарии обоих детских доступов, PIN, recovery и invitation. | Один профиль; отказ до подтверждений; потерянный ответ/повтор/expiry/неверная семья не расширяют права. |
| G3G05 | Гонки HTTP-команды с отзывом и lifecycle, обработка рестарта. | Данные после отзыва недоступны, уже завершённая операция не повторяется; ошибки транзакции не выглядят как успех. |
| G3G06 | Отчёт и остаток GAT/W11. | Отдельно перечислены доказанные synthetic HTTP e2e и ещё не проведённые реальные Telegram/device проверки; следующая среда/ключи/аккаунты согласуются отдельно. |

Среда: target runtime, loopback HTTP и существующий disposable PostgreSQL harness,
искусственные Telegram-векторы и fixture keys. Никаких сообщений ботом, публичного
сервера, настоящих семейных данных, deploy, новой графики или подключения demo UI
к реальной авторизации. Реальная Telegram-проверка требует отдельного согласования
конкретной среды и аккаунтов; эта карточка её не разрешает.
