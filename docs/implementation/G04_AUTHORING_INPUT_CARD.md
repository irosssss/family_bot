# G04-A — безопасный вход контентного конвейера

Версия 1.0, 2026-09-08. Разрешение: «да все работает, идем дальше по плану»
после проверки временной Telegram-версии. Первый самостоятельный блок W12;
W13–W15 сохраняются следующими частями G04.

| Работа | Приёмка |
|---|---|
| Ограниченный JSON parser | Duplicate keys до JSON.parse, fatal UTF-8, lone surrogates, NFC, глубина/число узлов/строки/байты. Числовые JSON-токены только точные small integers; UInt/Int остаются decimal strings. |
| Закрытый реестр JSON Schema 2020-12 | PackageInput v1 и LocalizationInput v1 с plain_text; запрет unknown record/schema, лишних и служебных полей, неявного coercion/defaults. |
| Локальный source boundary | Только явно перечисленные файлы, точный регистр, запрет traversal/ссылок/необычных файлов, namespace authority от вызывающего кода, суммарные лимиты. |
| Синтетический пакет и CLI | Машиночитаемый structural report, исходные SHA-256, ошибки file/pointer без содержимого; результат явно не production-ready. |
| Проверки и документация | Негативные CPT01/CPT03/CPT04 в области входа, точность parser/UInt для CPT02; regressions, typecheck/build и явный остаток G04. |

LimitsProfile `synthetic_content` r1: файл64KiB, пакет1MiB, 64файла,
глубина24, 10000значений на файл, строка4096UTF-16 единиц. Это тестовые пороги,
не принятие production O13. Реестр пока поддерживает только тексты без форматирования;
ICU, binary assets, игровые payload/handlers и их закрытые схемы не имитируются.

Symlink и hardlink запрещены полностью для первой версии. Корень — предоставленный
вызывающим кодом стабильный локальный снимок, без враждебного параллельного изменения
директорий. Node filesystem API не даёт этому reader переносимой openat-гарантии
при атакующем, способном одновременно заменять предков пути. Применение к такой среде
требует изолированного staging root/другого filesystem adapter.

Нет runtime-графики, основной БД, публикации, активации или изменения адреса бота.
Следующий блок G04-B/W13: exact dependency resolver, frozen lock/schema refs,
детерминированная канонизация и compiler для зарегистрированного типа, отрицательные графы.
