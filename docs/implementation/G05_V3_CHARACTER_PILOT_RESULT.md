## Профиль и ограничения

Цельный RGBA 1024×1536, contain без растяжения. Полная фигура заменяется вместе с комплектом; это не слой одежды поверх тела и не совместимость с ULPC. Спортивная дочь получает +22 исходных px по принятой Figma-поправке; изображение не редактируется.

Семейный масштаб 1/.93/.77/.65 пока применяется к общему холсту PNG, а не к измеренному силуэту. Это кандидат ростовки: посадка в дом и точные опорные точки требуют отдельного профиля. Глаза/волосы исходные, перекраска Figma в этот проход не экспортировалась. Смешивание этих PNG с отдельными глазами/волосами запрещено до проверки anchors/occlusion. Питомцы, уголок и мебель не добавлялись фиктивными заполнителями.
