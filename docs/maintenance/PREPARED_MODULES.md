# Подготовленные модули: назначение и границы

Эти модули сохранены из предыдущей работы, чтобы не потерять проверенные технические решения.
Они не являются альтернативными пользовательскими версиями приложения.

| Путь | Назначение | Что требуется до подключения |
|---|---|---|
| src/target, migrations/target, scripts/target | Доступ, согласия, identity, контентный конвейер G04 | Согласовать единую серверную архитектуру и интеграцию с текущим журналом V3 |
| src/v3-server, migrations/v3, src/v3-shared | Транзакционные команды, авторизация, журнал, модель семейной игры | Привести ранние правила к V3_BASELINE; не подключать старую экономику напрямую |
| src/v3/model | Ранняя модель, используемая сохранённым сервером и его тестами | Заменить/адаптировать при интеграции; текущие цены здесь не задаются |
| src/v3/assets | Проверки контрактов будущих составных ресурсов | Не заменяет действующий content-source/v3 |
| src/v3/live/transport.ts | Защита повторной отправки команды после потери ответа | Сверить с будущим транспортом; интерфейс live удалён |
| src/v3/access | Клиент согласий и доступа | Подключить после завершения реальной регистрации |
| src/preview/wardrobePilot | Просмотр исходных пользовательских комплектов | Инструмент художника, не отдельная версия игры |

Скрипт v3:local сохраняется для изолированного серверного стенда, а не для запуска
основного приложения. Основная команда — npm run dev. Существующие локальные базы,
секреты и Docker volumes при очистке не изменялись. Исторические миграции нельзя
применять к другой базе или удалять из уже применённой цепочки.
