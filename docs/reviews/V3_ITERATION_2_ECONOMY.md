**Пользователь выбрал B для прототипа.** Первая платная покупка48 требует6 принятых дел по8, базовый03 за72 —9дел, сезонный120 —15дел. При2/3принятых делах в день это3/2,5/3 и8/5дней. Принятая сетка цен применяется по порядковым позициям01–07 каждого героя; названия ниже — только по образцу дочери. Имена и соответствие арту других семейств нужно проверять отдельно, данный отчёт их не переименовывает; покупка личная, один платёж не открывает тему всей семье автоматически. Взрослый и ребёнок не получают разные цены. Графика 28 образов не означает необходимость покупать все 28 одним игроком.

Все сезонные по одной цене: без искусственной редкости, боевых преимуществ, таймера, повышения цены за пропуск и исчезновения приобретённого. Для пилота предлагается постоянная доступность всех шести платных; сезонность — тема оформления. Это предложение выкладки, не новая ограниченная акция.

### Формула и чувствительность

`дела = ceil(max(0, цена − доступный баланс) / монеты за принятое дело)`; `дни = ceil(дела / принятые дела в день)`. Для покупок вместе сначала сложить цены. При разной награде считать последовательность реальных начислений, а не среднее с ложной точностью.

Для принятого сезонного комплекта за120 при награде4 вместо8 нужны30дел (15/10дней при2/3); при12 —10дел (5/4дня). Это чувствительность, не предложение изменить награду. Семидневная задержка проверки может сдвинуть доступность покупки на неделю: отправленные дела ещё не доход. Это относится и к взрослому, чьё дело проверяет другой взрослый. Исключение единственного взрослого позволяет подтвердить самому, но не добавляет бонуса или автоматического дохода до подтверждения. Сроки таблиц считают уже принятые дела; для календарного прогноза отдельно измерять задержку review детей и взрослых. Пропущенные дни растягивают календарь, не отнимают монеты. Два/три дела — сценарии расчёта, не дневная норма ребёнка. Число членов семьи не умножает личный доход; совместная работа платит долю, не полный бюджет каждому.

В рабочем прототипе нового каталога нет причин сохранять цену60 ради старой демонстрационной арифметики400−60. Начальный кошелёк сценария можно задать тестовыми данными с явной подписью вне интерфейса; он не является обещанным подарком.

Архивирование исходного пилота и новый каталог не разрешают забрать реальные приобретения: если такие приобретения обнаружатся перед runtime-миграцией, потребуется точный перечень и отдельное правило совместимости. Сейчас никаких реальных данных не исследовалось.
