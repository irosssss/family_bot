## Личная проверка в Present

Проверка выполнена действиями в браузере с наблюдением экранов, без подмены переменных через код:

1. Новый день Лизы:112 доступно,120 в резерве. Собственное дело → отправка → ожидание взрослого.
2. Клавиша T → внешний пульт → собственный тестовый вход Марины → PIN-макет → дом. Марина имеет100 доступных,0 в резерве.
3. Очередь показывает отправленное дело Лизы. Подтверждение сообщает8 монет/15 опыта Лизе и0 проверяющему.
4. T → продолжить Лизой:120 доступно,120 в резерве. Повторный вход в дело показывает принятое состояние.
5. Каталог → зимний комплект120 → примерка → условия → покупка. Осталось0 доступных и120 в резерве. Применение отдельно → герой → дом: Лиза в зимней одежде, остальные в прежней.
6. Повторный вход Марины:100/0 без изменений, зимний образ Лизы сохраняется в общей комнате.
7. После исправления текстовых привязок: Марина100 → «Команда двора»48. В примерке верное название и изображение; условия показывают остаток52 и кнопку «Купить за48 монет». Этот контроль завершён до покупки.
8. Отдельный новый сценарий единственного взрослого: в комнате Марина и двое детей. Свое дело → отдельное самоподтверждение → принято → дом с108 монетами вместо100.

PIN и смена аккаунтов здесь заранее заданные тестовые ответы. Клавиша T открывает внешний пульт, сохраняющий состояние; только «Новый день» сбрасывает пример.

## Дефекты, закрытые до приёмки

- QA обнаружил стаканы в проверке, которых не было в исходных условиях. Условие согласовано во всех состояниях; обновлённый текст виден в Present.
- Исправлены переходы кнопок героя, обрезанная инструкция пульта и унаследованная реакция статического390-макета.
- Главный агент обнаружил в Present старое название «Мишка дома» при зимнем комплекте и неверное «останется400» при120−120. После клонирования потерялись текстовые привязки и сохранились старые aliases в свойствах экземпляров. Исправлены оба уровня девяти полей; независимый повторный аудит и браузерный контроль100−48=52 пройдены.
- Для сценария единственного взрослого скрыты слот Алексея и его внешний вход. Обычный старт восстанавливает семью из четырёх участников. Solo-комната и награда проверены лично.

## Границы результата и следующий шаг

Это связанный прототип одного примерного дела, не готовое приложение. PIN, серверная авторизация, синхронизация между устройствами и сохранение после перезапуска не реализованы. Резерв показан существующей суммой; отдельный цикл обещания остаётся в предыдущих макетах. Персонажи в комнате декоративны: чужие дела/кошельки по портрету не открываются.390 проверено только для статического дома; полноценного прохода на физическом телефоне/Telegram WebView не было. Сборка и тесты приложения не запускались, поскольку runtime не изменён.

Следующий шаг — короткий тест прототипа со взрослым и ребёнком по сценарию QA, фиксация затруднений, затем решение о переносе согласованного сценария в приложение. Новые ключевые правила не вводились.
