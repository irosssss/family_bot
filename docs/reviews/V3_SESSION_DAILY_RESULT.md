## Ограничения и вопросы главной сессии

1. Взрослый демонстрационный цикл завершён. Начальная очередь содержит одно дело Лизы (карточка Миши скрыта только в клоне), поэтому после решения очередь обоснованно пуста. Это выбранный пример дня, а не ограничение числа детей/дел. Порядок проверки и суммы не изменены.
2. Форма пояснения статическая: показан готовый текст «На полу остались две книги. Поставь их на нижнюю полку», совпадающий с детской доработкой. Ввод, валидация пустого текста, сохранение на сервере не имитируются. Техническая подсказка о прототипе убрана из UI и вынесена сюда и в ревью-блок.
3. Собственные дела взрослого, прочие вкладки, история, профиль и глобальная навигация вне данного сценария. Кнопка «Мои дела» на пустой очереди скрыта в клоне, чтобы не вести к чужому профилю. Нижняя навигация сохранена как контекст без привязок вне страницы.
4. Противоречивые переходы детских состояний устранены непосредственно в графе Figma. Ожидание открывает отдельные условия без «Готово», принятие — отдельный принятый список, доработка — отдельный список доработки. Backend для непротиворечивости этих переходов не требуется. Реальную сетевую идемпотентность статический прототип не тестирует.
5. Формальные измерения контраста WCAG, тест с детьми, интерактивный проход в Figma Present и Telegram WebView не выполнены. Статические скриншоты, геометрия и проверка графа не заменяют их. Код приложения, lint/runtime не затрагивались.
6. Новых продуктовых правил для согласования нет. Цены, начисления, получатели, обещания, безопасность и монетизация сохранены. Взрослая игровая роль уточнена прямым решением ниже.

## Подтверждённое уточнение модели V3

Во время работы главная сессия передала прямое решение пользователя: «Взрослые тоже играют — как в новых экранах V3». Действующая модель: у взрослого есть собственные дела, личные монеты и опыт. За проверку чужого дела отдельной награды нет. Это решение не требует повторного согласования.

Текущая очередь Марины и её вкладка «Мои» соответствуют этой модели; награда в проверке адресована Лизе. Собственные дела взрослого не входят в семь экранов данной страницы. Backend и миграции не менялись.

Устаревший документ: `AGENTS.md`, раздел «Silent-failure квирки», пункт «Роли: папа/мама = админы (НЕ играют: без золота/босса/streak)». Это ограничение legacy-приложения больше не является продуктовым правилом V3. Документ здесь не редактировался, чтобы главная сессия внесла согласованное изменение централизованно. Прочие документы на полноту противоречий не аудировались.

Финальный скриншот доработки после исправления «Остались две книги» повторно получен и просмотрен: заголовок помещается в одну строку, остальные блоки не сдвинуты за границы.

Приёмка главной сессией ещё не выполнена.
