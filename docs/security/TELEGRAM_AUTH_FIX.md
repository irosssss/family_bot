# Исправление legacy Telegram HMAC

2026-09-07. Разрешено пользователем: «ну так нужно решить эту ошибку». Исправлено в рабочем дереве; это отдельное исправление действующего входа, не реализация всего G03.

## Причина и исправление

Валидатор составлял строку подписи из URL-кодированных пар. Тестовые signer повторяли ошибку. Теперь query разбирается один раз, значения не декодируются повторно, JSON не пересериализуется; все поля кроме hash сортируются и соединяются LF. signature при наличии входит в HMAC.

Основание: [Telegram Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app), независимая сверка разбора query с [исходником сторонней init-data-golang](https://github.com/Telegram-Mini-Apps/init-data-golang/blob/master/validate.go). Новых зависимостей нет.

Общий строгий parser отклоняет дубли декодированных ключей, повреждённые percent-escape/UTF-8 и неоднозначные разделители. Сохранены строгий hash и timing-safe comparison. auth_date проверяется как положительное безопасное целое. Существующее окно 24 часа / допуск 60 секунд не менялось; оно не обеспечивает одноразовость входа.

parseInitDataUser использует тот же parser и требует положительный безопасный числовой ID. Middleware /api/auth/verify теперь отвергает отсутствующего/некорректного пользователя, вместо успешного ответа без проверенного user. Подпись по-прежнему проверяется до использования identity.

Сначала sandbox запретил listen на loopback для интеграционных тестов (EPERM); повтор с разрешённым запуском завершился успешно. Доказательства: [регрессия](../../work/auth-fix/regression.log), [lint](../../work/auth-fix/lint.log), [ошибки до исправления](../../work/auth-fix/before.log), [независимый vector](../../tests/fixtures/telegram-init-data.json).

Проверены вызовы из globalApiAuth, регистрации, verify middleware и configureSocketServer. Успешная регистрация с записью настоящего пользователя и реальный Telegram end-to-end не выполнялись. БД, ассеты и UI этим исправлением не менялись. SP01–SP17 и G03-B остаются отдельными предложениями; старый ошибочный HMAC не поддерживается как fallback.
