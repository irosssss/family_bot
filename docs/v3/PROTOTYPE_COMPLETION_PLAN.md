# Завершение игрового прототипа V3

Дата: 2026-09-11. Пользователь принял деревянное оформление и поручил постепенно выполнить следующий план, разрешив разделить независимую работу между агентами. Это продолжение Figma-прототипа; публикация, текущий бот и реальные семейные данные не входят в работу.

## Очередь

| Блок | Проверяемый результат | Статус |
|---|---|---|
| Вход и профили | Создание семьи, приглашение, свой Telegram ребёнка, общий телефон, повторный вход и восстановление | Figma:20 экранов;4 основные ветки проверены браузером |
| Дела | Создание → выполнение → проверка/возврат → подтверждённая награда; собственные дела взрослого; управление отдельно | Figma:50 экранов;10 логических сценариев PASS, основной и совместный цикл проверены браузером |
| Персонажи | Взрослая/детская базы и совместимая сменная одежда, одинаковая внешность в нескольких масштабах | Частично:детская база+туника приняты для Figma;взрослый кандидат без alpha,полная поставка не готова |

## Сохраняемые правила

Взрослые тоже играют и самостоятельно отмечают собственные результаты. Детские результаты проверяет взрослый. Реальные семейные награды доступны детям. Telegram identity не определяет роль в семье; роль следует из членства/приглашения. Смена просматриваемого героя не меняет авторизованный профиль. Условия уже открытого дела сохраняются при изменении расписания, семейной цели и питомца.

## Способ работы

Существующие 57 экранов и общие деревянные мастера остаются исходной проверенной версией. Новые сценарии собираются из этой библиотеки на выделенных страницах. Для каждого блока сохраняются спецификация, точные node IDs, ссылки, визуальная проверка и ограничения. Статические переходы Figma не объявляются сохранением данных или выполнением серверных команд. Техническая основа V3 уже существует отдельно; изменения интерфейса сначала проходят проверку сценария.

Локальные документы старых этапов, в которых написано «без ассетов» или «следующий этап только графика», описывают прежний объём. Новое поручение разрешает работу над недостающими сценариями и художественным пилотом в прототипе. Генерация полного ассортимента до проверки совместимости пилота не требуется.
