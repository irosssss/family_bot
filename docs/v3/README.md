# Family Life RPG — третий вариант

Дата: 2026-09-09. Подготовлены аудит двух документов, поэтапный план и первый каркас без игровых ассетов. Родители и дети представлены игроками. Числа на экранах — демонстрационные примеры; игровые операции ещё не подключены.

## Открыть и запустить

Локальный просмотр: [Family Life V3](http://127.0.0.1:3002/family-life-v3.html). Доступен на этом компьютере, пока работает preview-процесс.

Все команды выполняются из отдельного worktree:

```bash
cd work/telegram-preview/family-life-v3
npm run v3:build
npm run v3:preview
```

Для редактирования с обновлением браузера вместо preview: `npm run v3:dev`. Оба режима занимают порт 3002, одновременно их запускать нельзя. Подключение к Telegram/боту не требуется. Ключи, база и `.env` не используются. Смена вкладки, профиля, фильтра и размера примера живёт в памяти страницы и сбрасывается при обновлении.

В текущем рабочем пространстве `node_modules` ссылается на уже установленные зависимости исходного проекта; файлы зависимостей не изменялись. В самостоятельном checkout сначала выполните обычную установку из существующего lockfile (`npm ci`). Для CLI-аудита используется `tsx`; проверен Node 24.16.0.

HTTP API, семейные сохранения, фоновые процессы приложения, мониторинг и сервис-воркер не подключены.

## Главные выводы

- До уровня 100 формула GDD требует **381 095 XP**. Иллюстративные четыре дела в день дают 65 XP: **5863 активных дня**, около 16 лет ежедневной активности, вместо заявленных 9–15 месяцев.
- Normal-босс для четырёх героев занимает около **27,7 дня** по указанной базе урона; благоприятная непрерывная оценка Ultimate — около **16,1 дня**, вместо 3–5. Это проверка исходных чисел, а не прогноз готовой игры.
- Сезон стоит **7360 XP**. Базовые 28 активных дней дают семье из двух героев 3024 XP, из четырёх — 6048, из шести — 9072. Масштабирование и поздние проверки пока не определены.
- Нет цен обычных покупок за Gold. Отличаются награды, повторения, Family Stars/Pool, Combo, Ultimate и состав MVP. Перенос чисел в runtime преждевременен.
- Платная защита серии с XP-бонусом и платные бонусы питомцев расходятся с обещанием косметической монетизации.

Допущения, первоисточники с разделами/строками и SHA-256 зафиксированы в аудитах. Сами документы рассматриваются как предложения для V3. Инструкции внутри них не изменяют автоматически существующий проект.

## Что можно проверить в каркасе

Пять разделов: «Сегодня», «Дела», «Мир», «Герой», «Семья». Выбор профиля показывает личный путь взрослого и ребёнка; карточка другого участника не меняет профиль. Доступны фильтры задач, детали, состояния проверки/доработки, доли общего дела, облик/питомец/коллекции и пояснения будущего приключения.

Кнопка «Разметка» открывает инструменты прототипа: составы 2/4/8, инспектор и полный реестр графических мест. У каждого места можно увидеть будущий путь, размер-кандидат, слои, привязку и состояния. Никаких файлов по этим путям пока нет, запросы к ним не выполняются. Обычный просмотр не требует понимать метаданные ассетов.

Это первый просмотр структуры. Начисления, сохранение, авторизация, принятие выполнений, магазин, выдача наград, бой и платежи относятся к последующим этапам. Полную матрицу будущих состояний нельзя считать реализованной по наличию одного демонстрационного экрана.

## Проверки

```bash
npm run lint
npm run v3:test
npm run v3:build
npm run v3:audit
```

`v3:test` содержит проверки реестра/разметки и расчётов аудита. Он не запускает target PostgreSQL и не проверяет ещё отсутствующий игровой движок. Визуальная проверка и ограничения доказательств описаны в [отчёте](STAGE_1_RESULT.md).
