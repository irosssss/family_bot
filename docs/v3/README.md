# Family Life RPG — третий вариант

Дата: 2026-09-09. Этап 2 завершён в объёме [отчёта](STAGE_2_RESULT.md): подготовлены продуктовый и командный контракты, числовая модель, offline-симуляция и расширенная витрина состояний. Версия v0.1 имеет статус **предложения**; завершение подготовки не означает утверждение всех правил или готовность игрового сервера.

Пользователь уже подтвердил: родители тоже игроки; взрослый сам отмечает собственные дела по доверию, детский результат принимает взрослый; реальные семейные награды пока только детям. Конкретные числа, цель, питомцы, каталог и технические механизмы остаются предложением для проверки и обсуждения.

## Открыть и запустить

Локальный просмотр: [Family Life V3](http://127.0.0.1:3002/family-life-v3.html). Доступен на этом компьютере, пока работает preview-процесс.

Все команды выполняются из отдельного worktree:

```bash
cd work/telegram-preview/family-life-v3
npm run v3:build
npm run v3:preview
```

Для редактирования с обновлением браузера вместо preview: `npm run v3:dev`. Оба режима занимают порт 3002, одновременно их запускать нельзя. Подключение к Telegram/боту не требуется. Ключи, база и `.env` не используются. Навигация, выбранный профиль, фильтры, состояния и условия калькулятора живут в памяти страницы и сбрасываются при обновлении; browser storage не используется.

В текущем рабочем пространстве `node_modules` ссылается на уже установленные зависимости исходного проекта; файлы зависимостей не изменялись. В самостоятельном checkout сначала выполните обычную установку из существующего lockfile (`npm ci`). Для CLI-аудита используется `tsx`; проверен Node 24.16.0.

## Что показал аудит исходных документов

- До уровня 100 формула GDD требует **381 095 XP**. Иллюстративные четыре дела в день дают 65 XP: **5863 активных дня**, около 16 лет ежедневной активности, вместо заявленных 9–15 месяцев.
- Normal-босс для четырёх героев занимает около **27,7 дня** по указанной базе урона; благоприятная непрерывная оценка Ultimate — около **16,1 дня**, вместо 3–5. Это проверка исходных чисел, а не прогноз готовой игры.
- Сезон стоит **7360 XP**. Базовые 28 активных дней дают семье из двух героев 3024 XP, из четырёх — 6048, из шести — 9072. Масштабирование и поздние проверки пока не определены.
- В исходных документах не было цен обычных покупок за Gold. Отличались награды, повторения, Family Stars/Pool, Combo, Ultimate и состав MVP. Поэтому этап 2 вводит отдельную явно предложенную модель и каталог, а не переносит эти числа незаметно.
- Платная защита серии с XP-бонусом и платные бонусы питомцев расходятся с обещанием косметической монетизации.

Допущения, первоисточники с разделами/строками и SHA-256 зафиксированы в аудитах. Эти расчёты описывают прежние предложения: например, текущая кривая v0.1 уже другая. Для новых чисел использовать только BALANCE и его модули. Инструкции исходных документов не изменяют автоматически существующий проект.

## Что можно проверить в витрине этапа 2

Пять разделов: «Сегодня», «Дела», «Мир», «Герой», «Семья». Выбор профиля показывает личный путь взрослого и ребёнка; карточка другого участника не меняет профиль. Доступны фильтры задач, детали, состояния проверки/доработки, доли общего дела, облик/питомец/коллекции и пояснения будущего приключения.

Кнопка «Разметка» открывает инструменты прототипа: составы 2/4/8, инспектор, «Состояния экранов» и «Посчитать баланс v0.1». В реестре 14 нейтральных мест; у каждого можно увидеть будущий путь, размер-кандидат, слои, привязку и состояния. Файлов по этим путям пока нет, запросы к ним не выполняются.

| Группа примеров | Доступные состояния |
|---|---|
| Общая цель — 3 | Не выбрана, частичный прогресс, достигнута |
| Питомец — 3 | Пока нет, известное яйцо, спутник с бесплатным уголком |
| Вещь — 4 | Хватает золота, недостаточно, получена, применена |
| Реальная награда — 5 | Идея, ждёт согласования, согласована и ждёт выдачи, получена, отменена с освобождением резерва |

Это **независимые view fixtures**, а не последовательность исполненных команд. Переключение не отправляет результат дела, не начисляет Gold, не покупает предмет и не выдаёт награду. Резерв показывается и при ожидании согласования, и после согласования; списание — только в примере фактической выдачи. Калькулятор отдельно сравнивает 1/2/4/6/8 героев, 20/28 активных дней и три рутины, читая ту же модель чисел.

Расширенная матрица включает также будущие отмены, ошибки и восстановление. Наличие этих описаний или view fixtures не доказывает надёжность отсутствующих серверных операций. Начисления, сохранение, авторизация, покупки, выдача наград, бой и платежи относятся к следующим этапам.

## Проверки

```bash
npm run lint
npm run v3:typecheck
npm run v3:test
npm run v3:build
npm run v3:simulate
npm run v3:audit
```

На этапе 2 прошли `lint`, отдельный `v3:typecheck`, **26 V3-тестов** и сборка. Тесты охватывают реестр/разметку, исходный аудит и новую арифметическую модель. `v3:simulate` воспроизводит предложение v0.1; `v3:audit` сохраняет историческую проверку исходных документов. Ни одна из этих проверок не запускает target PostgreSQL и не доказывает работу будущего settlement, резерва или авторизации. Фактический охват браузерной проверки 375/390 px и ограничения доказательств — в [отчёте этапа 2](STAGE_2_RESULT.md).
