Дополнительно:

- `GET /v3/api/bootstrap` получает game/session из одной проверенной cookie/actor. Порядок запросов и epoch защищают UI от запоздавших чтений, в том числе после admin-операции без увеличения game revision. Эффект roster имеет cleanup и игнорирует старый ответ.
- Начало switch/logout блокирует параллельные действия и инвалидирует чтения. При переключении показывается загрузка; промежуточный экран входа устранён. Неизвестный pending-запрос сохраняет тело, ключ и ожидаемого участника при повторе.
- Возобновление участия в игре меняет ключ открытия дня: сегодняшняя работа может материализоваться без перезагрузки страницы. Ключ не зависит от XP/кошелька или каждого game revision.
- Перед выполнением видны зафиксированные цель и приключение, включая отсутствие адреса. Исторические начисления не переписываются.
- Значение progressbar ограничено диапазоном min/max, а реальное накопление остаётся текстом. Слои будущей графики имеют ключ по уникальной роли, даже если повторно используют один PNG.

## Скиллы и первичные источники

Для фазы ревью прочитан локальный `review-agent`; для мобильной проверки использован `frontend-design`. Рекомендованные Hermes-скиллы не найдены в текущем runtime и не объявляются использованными. После read-only фазы ревью исправления выполнены в рамках разрешённой работы V3.

- Для обработки запоздавших запросов использован cleanup/ignore-подход, описанный в [React useEffect](https://react.dev/reference/react/useEffect#fetching-data-with-effects), дополненный номером запроса и epoch приложения.
- Проверен единый порядок блокировок относительно [PostgreSQL18 explicit locking](https://www.postgresql.org/docs/18/explicit-locking.html#LOCKING-DEADLOCKS); нового дефекта в family-first границе не обнаружено.
- HMAC-проверка Telegram сопоставлена с [официальной проверкой initData](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app): текущий bot-token путь сохранён; его не смешивали с отдельной third-party Ed25519 проверкой.
- Доступный диапазон прогресса проверен по [WAI-ARIA progressbar](https://www.w3.org/TR/wai-aria-1.2/#progressbar).
