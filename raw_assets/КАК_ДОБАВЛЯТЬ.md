# Как закидывать свои ассеты (сгенерированные на сайте Gemini)

## Куда класть

Скачай картинку из Gemini и положи в папку:

```
raw_assets/inbox/
```

**Имя файла = что это**, например:
- `boss_dragon_ref.png` — референс нового босса-дракона
- `items_kit_1.png` — кит предметов (несколько на одной картинке)
- `pet_hamster.png` — новый питомец
- `bg_volcano.png` — фон

## Что писать мне после этого

Просто напиши в чат:
> «Закинул boss_dragon_ref.png — сделай босса»

или

> «Закинул items_kit_1.png — нарежь и добавь в магазин»

Всё остальное сделаю я: нарежу, уберу фон, приведу к размерам игры, подключу в код, обновлю манифест.

## ШПАРГАЛКА ПРОМПТОВ для сайта Gemini

### Общие правила (важно!)

1. **Никогда не пиши «transparent background» / «прозрачный фон»** —
   Gemini нарисует шахматку вместо прозрачности.
   Пиши: «centered on a solid medium-gray background» (сплошной серый).
2. **Цвет фона подбирай под сцену игры** (чтобы убрать без ореолов):
   - лес/природа → dark-green
   - небо/подземелье → dark-gray или steel-blue
   - универсально → medium-gray
3. Стиль нашей игры: **32-bit pixel art RPG** (как Pokemon/Secret of Mana).

---

### БОСС (референс)

```
A pixel-art game boss: {ОПИСАНИЕ, например "giant angry onion king with a crown,
tears dripping"}. 32-bit JRPG style like Secret of Mana. Bold outlines,
rich colors. Single centered character, full body visible,
on a solid medium-gray background.
```

Размер: 1K (1024). Один босс = одна картинка.

### КИТ ПРЕДМЕТОВ (дёшево: 1 генерация = 4-6 предметов)

```
A 2x2 grid of pixel-art RPG items on solid medium-gray background,
equal cells, thin gaps between items: top-left {ПРЕДМЕТ 1},
top-right {ПРЕДМЕТ 2}, bottom-left {ПРЕДМЕТ 3}, bottom-right {ПРЕДМЕТ 4}.
32-bit RPG style, bold colors, each item centered in its cell.
```

Я разрежу по сетке и добавлю в магазин как отдельные предметы.

### НОВЫЙ ПИТОМЕЦ

```
A small pixel-art pet {животное}, side view facing LEFT, full body standing,
32-bit RPG style like Pokemon followers, bold outline, on a solid
dark-green background. The pet fills most of the frame height.
```

Обязательно: **side view facing LEFT** (так питомец идёт за героем).

### ФОН ЛОКАЦИИ

```
A pixel-art game background: {локация, например "volcano cave with lava flows"}.
32-bit JRPG style, no characters, no UI, wide landscape composition.
Muted colors suitable as a game scene backdrop.
```

## Технические размеры игры (для справки)

| Тип ассета | Итоговый размер в игре |
|------------|------------------------|
| Босс | кадр 128x128 (спрайтшит 5 кадров) |
| Предмет-иконка | 64x64 |
| Питомец | кадр 64x64, отображается 56px |
| Фон сцены | 1376x768 (fullscreen) |
| Фон карточки игрока | 480x360 |

Gemini выдаёт 1K (1024px) — это нормально, я уменьшу сам.
