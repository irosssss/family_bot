# V3 — основной интерфейс

- Актуальная основа: `docs/V3_BASELINE.md`; пользователь разрешил объединение V3 и переход основной ветки на неё.
- Действующий интерфейс: `V3App.tsx`, `*Panel.tsx`, `domain.ts`, `session.ts`, `content/`.
- Цены и IDs: `content-source/v3/`. Не менять ключи сохранений и журнал без миграции.
- Родители играют; режим проверки задаётся при создании дела. Общая кампания и ручной удар согласованы.
- Старые `App.tsx`, `live/`, `model/` и `assets/` пришли из раннего этапа ветки. Они не задают текущие правила. Перед удалением проверить серверные зависимости.
- Исходные пользовательские комплекты сохранять. Новые изображения не генерировать в рамках объединения.
- Проверки: lint, каталог, тесты и сборка; мобильный интерфейс 375–390px.
- Не открывать реальную регистрацию и не заменять локальную сессию незавершённым сервером.
