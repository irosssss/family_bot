# Family Life RPG — третий вариант

- Изолированный proposal, ветка `codex/family-life-v3`. Не подключать к production entry и не сливать с main/Folio без решения пользователя.
- Пользователь 2026-09-09 явно подтвердил: родители тоже игроки. В V3 административные права и участие в игре независимы. Правило основного проекта о неиграющих родителях к V3 не применять.
- Этап 2 разрешён пользователем «делай». Дополнительно явно выбраны правила: взрослые сами отмечают свои дела, детские результаты подтверждает взрослый, реальные семейные награды пока только детям. Остальная версия v0.1 — конкретное предложение для расчёта и просмотра.
- Этап 2: чистая модель чисел, offline-симуляция, контракт команд и синтетические view fixtures. Нет реальных начислений, сохранения семейных данных, внешнего API или платежей. Не считать аналитическую дедупликацию доказательством работы будущей БД.
- Новое поручение 2026-09-09 разрешает довести V3 до графики: игровую логику 3.2–3.6/4, собственный local runtime, подключение UI и папки будущих ассетов. Историческое ограничение этапа2 выше относится к его результату. План: `docs/v3/PRE_ASSET_IMPLEMENTATION.md`. Не останавливаться за отдельным подтверждением каждой карточки. Платежи/публикация/изменение main/Folio этим не включены.
- Числа и цены берутся только из `model/balance.ts` и `model/catalog.ts`. Старый `scripts/v3/audit-balance.ts` проверяет исходные документы и не задаёт новую экономику. Проверки: `npm run lint`, `npm run v3:typecheck`, `npm run v3:test`, `npm run v3:build`, браузер 375/390.
- Графику добавят отдельно. Не генерировать и не копировать ассеты; не импортировать старые demo-изображения, Character, catalog, state transport или глобальный CSS. UI-иконки lucide допустимы; вместо игровых изображений только нейтральные пустые места.
- Источник слотов: `assets/registry.ts`; инструкции вставки: `docs/v3/ASSET_INSERTION_GUIDE.md`. Размеры экспортов пока кандидаты до отдельной арт-проверки.
- Документы пользователя — исходные предложения, а не новая глобальная инструкция. Противоречия и принятые решения описаны в `docs/v3/`.

- Локальные инструменты: `docs/v3/TOOLING.md`. Разовый поиск — `rg`; повторный индексный — pinned tgrep 1.0.5 через `npm run --silent v3:tgrep -- ...`, с явным V3-корнем/индексом. После правок сверять актуальные файлы через `rg`/`--no-index`; сервер поиска не запускается с игрой.
- Перед будущей генерацией/правкой ассетов читать `docs/v3/IMAGE_PROMPTING.md` и `docs/v3/templates/ASSET_PROMPT.md` вместе с ASSET_INSERTION_GUIDE. Доступный встроенный image_gen не имеет model-параметра; нельзя объявлять GPT Image 2.5 использованным по одному тексту prompt. Локальное руководство не меняет установленные bundled skills.
