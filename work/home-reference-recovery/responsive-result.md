# Новый вечерний дом: мобильный и web

Прямой запрос пользователя после отклонения тесного фона: сгенерировать новый вариант для обоих форматов. Получен один широкий мастер; это предложение новой композиции в выбранном вечернем стиле, не точная копия геометрии05. Встроенный image_gen, не CLI, без расходов SpriteCook.

## Что проверено

- Один и тот же PNG в обеих версиях; `object-fit:cover; object-position:center`, без растяжения по одной оси.
- Реальные375/390/1280через CUA: изображение загружено, документ не шире viewport, вся семья2+2видна; проверены лица, руки, ноги детей и близость к родителям.
- Полноэкранный9:16crop оставляет людей, но сильно срезает диван. Для реального мобильного хаба выбран preview3:4: более широкий охват комнаты при наличии места под прочий UI. Desktop16:9показывает боковые зоны и камин; в мобильном кадре камин не виден.
- После проверки временный override viewport сброшен. HTML-preview сохранён отдельной вкладкой. Изменений игрового состояния не было.
- Первый screenshot сразу после создания вкладки был захвачен до корректного отображения картинки; повторная DOM/visual-проверка показала верный кадр, сохранённый mobile375заменён проверенным результатом. Не использовать первый некорректный кадр как доказательство.

## Ограничения

Это **цельная сгенерированная иллюстрация**. Семья, мебель и фон ещё впаяны в один рисунок. Она не доказывает кастомизацию, расстановку любого состава семьи, покупки/питомцев или готовность приложения. Страница — fixture для проверки кадрирования, не новая HomeScreen. Пользователь ещё не принял этот кандидат.

Следующий шаг после оценки композиции: отдельные room/sofa/foreground/character layers и совместимые позы; затем подключение к существующей модели данных и проверка настоящего приложения. Остальные страницы пока не менять. Предыдущее ограничение внешней загрузки SpriteCook остаётся; этот запрос генерации его не отменяет.
